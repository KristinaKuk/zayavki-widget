# Заявки — Windows-виджет

Небольшое нативное Windows-приложение для быстрого доступа сотрудников к корпоративной системе заявок.

## Что уже есть

- компактное окно 360×470;
- кнопка «Новая заявка»;
- переход в корпоративную систему;
- «Новые», «В работе», «Мои заявки»;
- режим поверх других окон;
- сборка Windows через Tauri в `.msi` и `.exe`-установщик NSIS.

## Стек

- Tauri 2
- React 19
- TypeScript
- Vite
- Rust

## Важно

В `src/main.tsx` переменная `JOTFORM_APP_URL` пока содержит базовый адрес Jotform. После публикации приложения «Заявки» нужно заменить его на фактический пользовательский URL опубликованного приложения.

## Локальный запуск

```bash
npm install
npm run tauri dev
```

## Сборка Windows

```bash
npm install
npm run tauri build
```
